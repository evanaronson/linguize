# Standalone Practice removed

The correction drills and spaced-repetition scheduler have been removed. Linguize
is not adding another practice system now; a fuller practice mode is deferred.
Chat continues to provide conversation practice, and Teach me still explains an
individual change.

There is no Practice entry on Progress. Saved routes from older builds return to
Progress. The old `lab_practice.json` schedule file is no longer read or written;
removing the feature does not delete History, conversations, or saved phrases.
